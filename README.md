# FlowDesk - AI Productivity Assistant

Live App: https://ai-productivity-assi-vvsi.bolt.host

## Overview
FlowDesk is an AI-powered workplace assistant built for CAPACITI final project.
It helps with 4 daily tasks using expert prompt engineering.

## 4 AI Tools
1. **Email Composer** - Drafts professional emails (Role: Email Expert)
2. **Meeting Summarizer** - Summarizes long transcripts (Role: Analyst)
3. **Task Planner** - Creates prioritized plans (Role: Project Manager)
4. **Content Rewriter** - Rewrites tone (Role: Editor)

## Prompt Engineering
See `src/lib/assistant-prompts.ts` for 4 expert prompts using:
- Role, Context, Audience, Constraints, Tone, Format
- Each prompt > 100 words, responsible AI disclaimer

## Tech Stack
- React + TypeScript
- Gemini AI API
- Deployed on Bolt.host

## Responsible AI
This app includes disclaimer: AI-generated content must be verified before sending.
It does not make final decisions autonomously.
